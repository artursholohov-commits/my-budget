# Мой бюджет — PWA для iPhone

## Что входит
- 4 раздела: Добавить, Счета, Статистика, Цели.
- Локальное хранение в браузере (localStorage), без аккаунта и без обязательного облака.
- Доходы и расходы, категории и emoji, несколько счетов в BYN/USD/EUR.
- Цели с прогрессом и историей пополнений.
- Долги и фиксация погашения/возврата.
- Статистика за неделю, месяц, год или выбранные даты; круговая диаграмма и столбики.
- Экспорт и импорт JSON-копии.
- PWA-манифест, service worker и иконки.

## Важно про валюты
Курсы BYN/USD/EUR — ручные ориентиры в настройках, по умолчанию стоят примерные значения. В офлайн-приложении они не обновляются автоматически. Для переводов в цель и платежей по долгу приложение просит счёт в той же валюте, чтобы избежать незаметной конвертации.

## Как опубликовать
PWA устанавливается с HTTPS-адреса. Для самого простого варианта загрузите все файлы из папки на статический HTTPS-хостинг (например, GitHub Pages или Netlify). Убедитесь, что `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png` и `icon-512.png` находятся рядом.

## Установка на iPhone
1. Откройте HTTPS-ссылку в Safari (не во встроенном браузере мессенджера).
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. При наличии переключателя включите «Открывать как веб-приложение».
5. Нажмите «Добавить».
6. Запустите иконку «Мой бюджет». Первый запуск сделайте при подключённом интернете, чтобы кэш загрузился.

## Резервные копии
Внутри приложения нажмите стрелку в верхней части экрана или ⚙️ → «Экспортировать резервную копию». Сохраните JSON в «Файлы» / iCloud Drive. Для восстановления используйте импорт JSON в настройках.

## Ограничения прототипа
- Данные хранятся только в браузерном хранилище текущего устройства; синхронизации между устройствами нет.
- Очистка данных Safari или удаление веб-приложения может привести к потере локальных данных — регулярно делайте копии.
- Это функциональный прототип, не прошедший полноценное тестирование на всех версиях iOS. Перед использованием как единственного финансового журнала проверьте операции и резервное копирование на небольших тестовых данных.
- Переводы в цели уменьшают баланс счёта и не считаются потребительскими расходами в статистике.
