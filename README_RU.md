# Мой бюджет — PWA для iPhone

## Что входит
- 4 раздела: Добавить, Счета, Статистика, Цели.
- Локальное хранение в браузере (localStorage), без аккаунта и без обязательного облака.
- Доходы и расходы, категории и emoji, несколько счетов в BYN/USD/EUR.
- Цели с прогрессом и историей пополнений.
- Долги и фиксация погашения/возврата.
- Статистика за неделю, месяц, год или выбранные даты; круговая диаграмма и столбики.
- Экспорт и импорт JSON-копии.
- PWA-манифест, service worker и иконки.

## Обновление уже установленного приложения
1. Перед обновлением открой в приложении ⚙️ и экспортируй резервную копию JSON в «Файлы» или iCloud Drive.
2. Загрузи все файлы из этой папки в корень того же GitHub-репозитория, заменив старые файлы, и нажми **Commit changes**.
3. Подожди, пока GitHub Pages опубликует изменения.
4. Открой приложение с иконки при подключённом интернете. Service worker проверит новую версию и обновит кэш. Если интерфейс не изменился, полностью закрой приложение, открой ещё раз и подожди несколько секунд.
5. Не удаляй приложение и не очищай данные Safari: записи хранятся локально на устройстве.

## Публикация
Загрузи все файлы из этой папки в корень статического HTTPS-хостинга (например, GitHub Pages). `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png` и `icon-512.png` должны находиться рядом.

## Установка на iPhone
1. Открой HTTPS-ссылку в Safari (не во встроенном браузере мессенджера).
2. Нажми «Поделиться» → «На экран Домой».
3. При наличии переключателя включи «Открывать как веб-приложение» и нажми «Добавить».

## Валюты и резервные копии
Курсы BYN/USD/EUR задаются вручную в настройках. Для резервного копирования нажми стрелку в верхней части экрана или ⚙️ → «Экспортировать резервную копию». Для восстановления выбери импорт JSON в настройках.
